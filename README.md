# أجروميد — AGROMEED

متجر إلكتروني عربي (RTL) + لوحة تحكم + نظام إدارة عملاء (CRM) لشركة أجروميد للتنمية الزراعية والصناعية.
مبني على Next.js 16 + PostgreSQL 16 + Drizzle ORM + Tailwind CSS 4.

| | |
|---|---|
| الموقع | https://agromeed.com |
| لوحة التحكم | https://agromeed.com/admin |

---

## ما الذي يعمل الآن

**المتجر** — 7 صفحات عربية، 43 منتجاً بمواصفاتها الكيميائية ومعدلات استخدامها، بحث وتصفية،
وسلة «طلب عرض سعر». كل المحتوى يُقرأ من قاعدة البيانات، فأي تعديل في لوحة التحكم يظهر فوراً.

**لوحة التحكم** (`/admin`) — محمية بتسجيل دخول، غير مفهرسة في محركات البحث:

- **نظرة عامة** — مؤشرات حية، منحنى الطلبات في 30 يوماً، خط المبيعات، المنتجات الأكثر طلباً
- **العملاء والطلبات** — صندوق وارد لكل من يتواصل عبر الموقع، بحث وتصفية بالمرحلة،
  وصفحة لكل عميل بها: تغيير المرحلة، قيمة الصفقة، سجل المتابعة، وأزرار اتصال/واتساب/بريد
- **المنتجات** — إضافة وتعديل وحذف، محرّر لجداول التركيب والمميزات ومعدلات الاستخدام
  والعبوات والسعر، ومفتاح نشر/إخفاء لكل منتج
- **الأقسام** — تحرير أقسام الكتالوج
- **سجل النشاط** — كل تعديل إداري مسجَّل باسم من نفّذه ووقته
- **الإعدادات** — تغيير كلمة المرور، مستقبِلو إشعارات البريد ورسالة اختبار،
  وإدارة المستخدمين وأدوارهم (للمالك فقط)

**التقاط العملاء** — نماذج الموقع تُرسل إلى `/api/leads` فتُحفظ في قاعدة البيانات وتظهر
فوراً في لوحة التحكم، مع تحقق من المدخلات وحدّ لمعدل الطلبات وحقل فخ للبوتات.

**البريد** — عند ورود أي طلب يُرسَل إشعار لفريق المبيعات (ببيانات العميل والمنتجات
وأزرار اتصال وواتساب) وتأكيد للعميل برقمه المرجعي. الإرسال يتم بعد الرد على العميل
عبر `after()`، فلا ينتظر SMTP ولا يضيع طلب بسبب فشل بريد. يُضبط من
`/admin/settings` ومن متغيرات `SMTP_*`.

## الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| `owner` | كل شيء |
| `sales` | العملاء والطلبات فقط |
| `editor` | المنتجات والأقسام فقط |

الفحص يتم في طبقة الوصول للبيانات (`src/lib/auth/dal.ts`) عند كل استعلام وكل إجراء —
وليس في `proxy.ts` وحده، الذي يقوم بفحص مبدئي للتحويل السريع فقط.

## التطوير المحلي

قاعدة البيانات تعمل على الخادم ومنشورة على `127.0.0.1:55432` هناك فقط، فيُفتح إليها نفق:

```bash
ssh -f -N -L 55432:127.0.0.1:55432 root@187.77.67.160
cp .env.example .env    # ثم املأ القيم من /root/agromeed/db.env على الخادم
npm install
npm run dev
```

| أمر | الوظيفة |
|---|---|
| `npm run db:generate` | توليد ملف ترحيل بعد تعديل `src/db/schema.ts` |
| `npm run db:migrate` | تطبيق الترحيلات |
| `npm run db:seed` | إنشاء المستخدم الإداري وترحيل الكتالوج (آمن للتكرار) |
| `npm run db:studio` | واجهة استعراض قاعدة البيانات |

## النشر

```bash
ssh root@187.77.67.160 'bash /root/agromeed/deploy.sh'
```

السكربت: يسحب آخر نسخة من `main` ← يبني صورة الأدوات ← يطبّق الترحيلات ← يهيّئ البيانات
← يبني صورة التشغيل ← يعيد تشغيل الحاوية خلف Traefik بشهادة SSL تلقائية.

**البنية على الخادم**

| الحاوية | الدور |
|---|---|
| `agromeed-app` | تطبيق Next.js خلف بروكسي Traefik الخاص بـ Coolify |
| `agromeed-db` | PostgreSQL 16، بياناتها في الحجم `agromeed-pgdata` |

الأسرار في `/root/agromeed/db.env` على الخادم (صلاحية 600) — وليست في المستودع.

## النسخ الاحتياطي

نسخة يومية 3:15 فجراً عبر cron، تُحفظ في `/root/agromeed/backups` مع احتفاظ 14 يوماً
ونسخة أسبوعية كل أحد تُحفظ 120 يوماً. السكربت يرفض حذف القديم إذا خرجت النسخة فارغة.

```bash
ssh root@187.77.67.160 'bash /root/agromeed/backup.sh'                    # نسخة فورية
ssh root@187.77.67.160 'bash /root/agromeed/restore.sh <مسار الملف>'      # استرجاع
```

## ما زال مطلوباً قبل التسليم النهائي للعميل

1. **تغيير كلمة مرور المستخدم الإداري** — من `/admin/settings` مباشرةً.
2. **الأسعار** — كل المنتجات الآن «السعر عند الطلب». إدخال سعر في لوحة التحكم يجعله يظهر
   في المتجر مباشرة.
3. **جرومو فروتكس** — الكتالوج المطبوع يذكر البورون `40%`، وهي نسبة غير واقعية لسماد سائل.
   المعروض `4%` مؤقتاً — يلزم تأكيد من العميل.
4. **الخامات العشر** بيانات مبدئية — تُستبدل بقوائم الاستيراد الفعلية.
5. **نسخ احتياطي خارج الخادم** — النسخ الحالية على نفس الجهاز؛ يُنصح بنسخها لتخزين خارجي.
6. **إشعارات واتساب** — البريد يعمل، وواتساب بيزنس API لم يُفعَّل بعد.
